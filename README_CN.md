# known-unknowns [![skills.sh](https://skills.sh/b/wang-cankun/known-unknowns)](https://skills.sh/wang-cankun/known-unknowns/known-unknowns)

[English](./README.md) | 简体中文

这个 Agent Skill 服务于这样的时刻：你知道一件事值得认真讨论，却还不知道该问什么。普通的 AI 对话经常卡在三个地方：

- **你能判断，却无法完整解释。** 你能辨认出合适的感觉、区别或取舍，却缺少表达它的语言或框架。
- **你的选择可能已经透露出尚未被你认出的知识。** 某种模式、假设或熟练判断，会先影响你的决定，再被你意识到。
- **你无法询问一个从未听说过的选项。** 真正有用的那部分可能性，始终没有进入讨论。

因此这个 Skill 给 Agent 换了一项任务：先提供词汇，把尚未认出的模式带进讨论，介绍选项并进行检验，让你多看见问题的一个面向，再提出下一个问题。

## 安装

```bash
npx skills@latest add Wang-Cankun/known-unknowns   # 加 -g 可在所有项目使用
```

## 这张地图

| | 你知道 | 你不知道 |
| --- | --- | --- |
| **你已经意识到** | 已知信息（known knowns）：已经说清并确认 | 已知盲点（known unknowns）：知道问题存在，但还没有答案 |
| **你尚未意识到** | 未被意识到的已知（unknown knowns）：已经作用于判断，却尚未被自己认出 | 未知领域（unknown unknowns）：你甚至不会想到要问的选项 |

矩阵追踪的是意识状态；隐性知识追踪的是可言说性。一个判断可以是你明确知道自己拥有、却难以解释的；缺少的语言属于已知盲点，而已经影响选择但未被认出的标准属于未被意识到的已知。

每个区域对应一种推进方式：**确认并收束**已经确定的信息，**调查**已经明确的盲点（包括缺少语言或框架），**让尚未认出的模式被辨认出来**，**巡视选项空间**介绍你不会想到要问的选择。

## 一次讨论如何进行

- **草图开场** —— Agent 根据你的主题和它自己的领域知识先画出完整地图。第一版可以是错的：纠正一个具体判断，比回答一轮空白访谈更容易。
- **每轮一个面向** —— 每一轮重新画出紧凑的地图，先为其中一个区域贡献实质内容，再只问一个问题。
- **收尾简报** —— 经过一次跳出框架检查（地图之外是否还有足以改变结论的假设？）后，你带走一份简报：确认的词汇、做出的选择、以及仍未照亮的部分——可以直接粘进未来任何一次对话。

## 试试看

```text
$known-unknowns 我知道哪些界面让人觉得平静，却说不清原因。帮我找到描述它的词汇。
```

```text
$known-unknowns 我总是否定一些技术上不错的界面方案。帮我找出这些反应可能已经透露的标准。
```

```text
$known-unknowns 带我看看：为 AI 助手加入记忆，有哪些我可能还不知道的实现路线？
```

```text
$known-unknowns 帮我判断是否应该接受这份工作，并检验我可能忽略了哪些前提。
```

这个 Skill 会使用你选择的语言进行讨论。
